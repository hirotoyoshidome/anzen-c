# ANZEN-C

ANZEN-Cは、C言語で安全かつ保守しやすいコードを書くための規約、レビュー観点、チェック資産を管理するリポジトリです。

このリポジトリ自体にCの実装を配置することは主目的ではありません。別のCプロジェクトに適用するためのMarkdownドキュメントと、将来的にはスクリプトによるチェックを管理します。

## ドキュメント

- [C言語コーディング規約](docs/c-coding-standard.md)
- [レビュー用チェックリスト](docs/review-checklist.md)
- [規約の背景と補足](docs/rationale.md)

## 読む順序

1. まず [C言語コーディング規約](docs/c-coding-standard.md) を読み、基本方針と必須ルールを確認します。
2. 実装やレビューでは [レビュー用チェックリスト](docs/review-checklist.md) を使います。
3. 判断理由や補足知識が必要な場合は [規約の背景と補足](docs/rationale.md) を参照します。

## 前提

- C17を基本とします。
- GCCおよびESP-IDFのツールチェーンを考慮します。
- Linux/POSIX環境と組み込み環境の両方を対象にします。
- ESP-IDFを使うプロジェクトでは、FreeRTOS、割り込み、ヒープ制約、ターゲット依存APIを考慮します。
- 文書は日本語で管理します。
